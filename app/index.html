修改影片動作

1 選擇人物

在畫面中點選人物軀幹，系統會自動追蹤整個修改區間。

2 選擇要修改的片段

目前提供 1–10 秒，首尾各保留 2 幀原片。3 秒只是預設；更長片段尚未驗證品質，顯存需求也較高。

3 你想讓人物做什麼？

請自行填寫動作描述；系統會根據你的文字與這次上傳的影片重新生成，不會套用預製片段。

減少生成區域周圍的背景變形與閃爍，盡量維持原影片的場景。移動鏡頭或遮擋較多時仍可能需要調整。

進階設定與工作紀錄

每次依照你的動作描述重新生成，並接回所選影片。Seed 可用來固定隨機設定；同一設定不代表所有環境都會產生完全相同的結果。

執行紀錄


把原片中間一段，改成新的動作
  1. 匯入自己的影片，選定開始與結束。
  2. 將播放頭移到修改範圍，暫停並點人物。
  3. 等待人物選取完成，拖動播放頭檢查綠色範圍；選錯請重新點。
  4. 輸入動作、按「生成新片段」。完成後切換結果並匯出。
修改區間後須重新點人。3 秒不是固定限制。人物遮擋、快速動作或鏡頭移動可能影響品質；生成後請先預覽接合處。
關閉頁面不會停止生成。關閉 UI 時，在啟動視窗按 Ctrl+C；運行中的 Docker 工作不會因此被強制終止。
